**Challenge:**

Build an On-Chain Immortal AI Agent with Decentralized Memory and Cross-Platform Interoperability

On BNBChain.

**Description:**

Challenge developers to build a decentralized AI agent using Unibase’s Membase (decentralized AI

memory layer) and BitAgent (AI agent launchpad), featuring sovereign memory and cross-platform

interoperability.

The AI agent should demonstrate the ability to autonomously manage data, share knowledge across

platforms, and evolve based on interactions.

**Submission Criteria:**

• A working prototype or demo of the decentralized AI agent, and how to use Unibase memory layer.

• Source code hosted on GitHub with deployment and testing instructions.

• Relevant documentation and a demo video explaining how the agent leverages sovereign memory

and interoperability.

**Judging Criteria:**

• Innovation (30%): Novelty and creativity of the approach.

• Technical Complexity (30%): Feasibility and implementation of the technology.

• User Experience (20%): Ease of use and user-friendliness of the AI agent.

• Documentation & Presentation (20%): Clarity of the documentation and professional presentation.
